About the Project

Cloud Storage Waste Detector is a cloud-based project designed to identify duplicate files and analyze storage usage to help reduce unnecessary storage consumption.

Technologies Used

Amazon S3

Stores uploaded files.

AWS Lambda

Analyzes files and detects duplicates.

Amazon DynamoDB

Stores file metadata and analysis results.

Python & Streamlit

Provides the dashboard interface.

Key Features

✔ Duplicate file detection

✔ SHA-256 hash-based comparison

✔ Storage usage analysis

✔ Duplicate file identification
